# Веб-сайт медицинского центра (Meddical)

Учебный проект по веб-разработке (React + SCSS + CSS Grid).

## Описание проекта

Сайт представляет собой многосекционную посадочную страницу для клиники / медицинского центра с полной реализацией сетки компонентов на **CSS Grid** и **Flexbox**.

### Использование CSS Grid в проекте:
1. **Навигация и каталог услуг (`ServicesSection`):**
   - Вертикальная панель категорий услуг с фиксированным позиционированием по строкам (`grid-template-rows`, `grid-row: 1/2... 5/6`).
   - Сетка списка преимуществ клиники (`grid-template-columns: repeat(2, 1fr)`).
   - Основной макет блока услуг (`grid-template-columns: 158px 470px 324px`).
2. **Медицинские направления (`SpecialtiesSection`):**
   - Сетка 4x3 для отображения 12 отделений (`grid-template-columns: repeat(4, 1fr)`).
3. **Форма записи на прием (`AppointmentSection`):**
   - Двухколоночная сетка полей ввода (`grid-template-columns: repeat(2, 1fr)`).
4. **Секция новостей (`NewsSection`):**
   - Сетка 2x2 для карточек статей с промежутком `gap: 30px` (`grid-template-columns: repeat(2, 1fr)`).
5. **Информационные карточки и блоки (`HeroSection`, `DoctorsSection`, `ContactCardsSection`, `Footer`):**
   - Сетки карточек врачей, контактов и колонок подвала сайта с использованием CSS Grid.

## Архитектура проекта

```
src/
├── assets/                  # Графические ресурсы и иконки
├── constants/
│   └── assets.js            # Реестр путей и импортов ресурсов
├── components/
│   ├── layout/
│   │   ├── Header/          # Шапка сайта
│   │   └── Footer/          # Подвал сайта
│   └── sections/
│       ├── Hero/            # Главный баннер
│       ├── About/           # О клинике
│       ├── Services/        # Услуги и специализации
│       ├── Specialties/     # Каталог направлений
│       ├── Appointment/     # Запись на прием
│       ├── Doctors/         # Список врачей
│       ├── News/            # Новости и статьи
│       └── Contacts/        # Контактная информация
├── pages/
│   └── HomePage/            # Главная страница
├── App.jsx                  # Корневой компонент с маршрутизацией
├── main.jsx                 # Точка входа React
└── index.css                # Глобальные стили и сброс отступов
```

## Установка и запуск

1. Установка зависимостей:
   ```bash
   npm install
   ```

2. Запуск локального сервера разработки:
   ```bash
   npm run dev
   ```

3. Сборка для продакшена:
   ```bash
   npm run build
   ```
